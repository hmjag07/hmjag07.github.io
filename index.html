Automated trading bot

simulated GBM tape
0.5%equity risked per trade
185offline test checks
15maudit log cadence

Trades SPY hourly through Alpaca from an AWS EC2 server with systemd auto-restart. An SMA-trend and momentum strategy reconciles its target with the broker's actual position every bar, so a restart can never double-trade, and backtests replay the live code path.

Risk is capped with fixed-fractional sizing, ATR bracket orders, a leverage cap and a daily-loss kill switch. Every entry, exit and equity snapshot is logged and pushed to a public GitHub branch every 15 minutes.

ShippedStochastic calculus

Options pricing model

call price vs payoff · σ = 0.20
16×vectorised Monte Carlo speed-up
81%less standard error
195automated checks

Prices European options three ways: Black–Scholes closed form, vectorised Monte Carlo with antithetic and control variates, and implied-volatility root-finding. All five Greeks are computed analytically, by finite differences and by pathwise Monte Carlo.

Validated against 112 live out-of-the-money NIFTY quotes. Flat-volatility Black–Scholes lands within 7.9% mean absolute error near the forward, then breaks down in the wings where implied vol reaches 23% against a fitted 13.8%: the equity volatility skew.

ML-powered stock prediction

20NSE stocks
52look-ahead checks
±0.4%95% CI on RMSE gain

A walk-forward forecasting pipeline over five years of daily data: an LSTM with engineered lag, volatility and sector-momentum features, tested against ARIMA, Ridge and predict-zero baselines with Diebold–Mariano tests and block-bootstrap confidence intervals.

The honest result: no significant out-of-sample edge over ARIMA. The pipeline does recover a planted signal, so the null is real and not a bug.

A C++17 simulator of a 500-venue trading network: Dijkstra least-cost order routing plus a dynamic-programming portfolio allocator. Heap-based Dijkstra and a rolling-array DP cut end-to-end compute time by 88% against a textbook O(V²) and memoised baseline, with identical outputs.

Built on 150+ solved graph, memory and low-latency data-structure problems.
